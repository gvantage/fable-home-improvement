全屋定制第一次出图用这张表打勾。毫米尺寸见 [[shouna]]，橱柜见 [[chufang]]，计价见 [[quanwu-dingzhi]]。

| 位置 | 不做 | 做 |
|---|---|---|
| 衣柜下部 | 门内藏抽 | 外置抽：一步拉开，抽宽不被铰链吃掉 |
| 书桌下墙 | 墙面落到地 | 与台面同材的防踢挡板 |
| 衣柜尽端 | 圆弧层板 | 矩形开放挂衣 + 下抽（当天衣服中转） |
| 厨台 | 洗炒同一标高 | 高低台：洗区高于炒区（盆底 vs 锅口） |
| 地柜转角 | 两柜 90° 直插 | 转角柜 / 拉篮，内腔连续 |
| 鞋柜底 | 一层留空，鞋溢到地垫 | 两层留空：拖鞋 / 外出鞋分开 |
| 小卧室床 | 满铺地台「榻榻米」 | 排骨架：透气、少板材；收纳改走衣柜 |
| 餐边柜 | 大面积玻璃门 + 灯带 | 玻璃点缀 + 实板，中部留操作台 |
| 橱柜 | 无背板（墙当柜背） | 每单元封闭箱体背板，承重防潮 |

这些决定必须进首次方案，安装时再改等于重做。水电验收仍用 [[jiangong-yanshou]]，不要拿这张表去验管线。
