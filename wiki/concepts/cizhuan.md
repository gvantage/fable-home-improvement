种类先分清再买。吸水率越低越致密。厨卫阳台外墙认瓷质砖（E ≤ 0.5%）。完整种类对照见原始「瓷砖选购指南」。铺贴节点见 [[zhuangxiu-liucheng]]、[[jiangong-yanshou]]。

## 看包装与报告
- 认准优等品、执行标准 GB/T 4100-2015、生产地址、吸水率、放射性 A 类；要近期质检报告。
- 认 CCC。同批次同日期，翻纸箱侧面核对色号。
- **地砖认附录 G（E ≤ 0.5%）。** 墙砖旧资料常写认附录 H，是为了水泥砂浆更好咬合；墙面若也用全瓷（E ≤ 0.5%），必须瓷砖胶 + 薄贴 + 双组份背胶，不能只靠纯水泥砂浆。
- 「品牌总部在广东」不等于产地在广东。优先佛山 / 肇庆 / 清远，背面常见 LOGO 和「广东制造 假一赔十」。800×800 三片大约 23 kg 更扎实。

## 店里辨别
1. 釉面：针孔、杂点、色差、崩边。
2. 木棍轻敲中心：清脆带金属回响为烧结致密；沉闷、空洞声可能隐裂或密度不足。
3. 两块面对面叠放：四角无翘曲，中间缝隙均匀 ≤ 0.5 mm。旧资料十字对拼缝写 ≤ 2 mm。
4. 背面滴 3 滴水，约 5 分钟无渗透或极慢为优；瓷质砖吸水率 ≤ 0.5%。店测只作快筛，以检测报告为准。
5. 同尺寸更沉通常更好。钥匙 / 硬币适度划釉面（避开边角），无可见白痕更耐磨，目标莫氏硬度 ≥ 5。记号笔约 5 分钟能擦掉更抗污。
6. 湿区 45° 倒水，穿软底鞋试抓地力。厨卫地面建议湿态静摩擦系数 ≥ 0.6。

## 按空间选
| 空间 | 要点 | 规格 / 参数 |
|---|---|---|
| 客厅 / 餐厅 | 高耐磨、适度光泽 | 通体大理石、亮面釉面砖；750×1500 / 800×800。抛光 / 玻化也常见，采光好可用哑光、柔光 |
| 厨房 / 卫生间 | 防滑、抗污好擦 | 地面哑光釉面 / 仿古，静摩擦系数 ≥ 0.6；墙面可用亮光釉面。抛光砖不要铺卫生间 |
| 卧室 | 温润低噪 | 木纹砖、柔光哑光；地暖确认导热，升降温 ≤ 2℃/h |
| 阳台 / 露台 | 抗冻 | 优先 E ≤ 0.5%；E ≤ 3% 仅南方非冰冻区，北方户外禁用 |
| 过道玄关 | 耐磨防滑 | 防滑通体、防污釉面、木纹砖 |

口诀：耐磨看玻化，防滑选通体，艺术马赛克，省钱抛光砖，风格仿古砖，省心釉面砖。
规格粗参：100㎡ 内客厅 800×800，厨卫墙 400×800 竖贴显高、地 400×400。也有资料写墙砖常见 300×300 / 300×600，地砖 300 / 600 / 800 相对省钱。大砖铺贴人工大约 80–120 元/㎡。异形砖、木纹砖、文化砖、马赛克：砖+人工+美缝都贵，大面积伤钱包。小户型浅灰 / 米白柔光；深色亮面容易显压抑。展厅灯好看铺完发暗：拿小样回家看自然光，尽量看整板效果。见 [[keting]]、[[chufang]]。

## 核心参数
- 吸水率：墙地通用优选 ≤ 0.5% 瓷质砖；陶质砖（＞10%）仅干燥墙面。
- 耐磨：客厅、过道 PEI ≥ III 级，莫氏硬度 ≥ 5。
- 平整度：边直度、直角度偏差 ≤ 0.15%，翘曲度 ≤ 0.3%。
- 环保：必须放射性 A 类，室内无限制。

## 铺贴、损耗、批次
- 直铺损耗 5%–8%；斜铺、拼花、异形 8%–12%。合同常见约定瓷砖损耗 ≤ 8%，超额施工方承担，见 [[zhuangxiu-hetong]]。
- 下单备注同一窑炉批次；收货逐箱核色号；铺前预排砖。同批多留 3–5 片。
- 全瓷上墙：瓷砖胶 + 薄贴法 + 双组份背胶。玻化砖同样必须瓷砖胶。
- 留缝 2–3 mm。美缝等砂浆干透，常见间隔约一周。缝隙清洁干燥再施工。合同写材料全称、品牌、颜色、是否含阳角、缝深、质保，不要只写「美缝」。见 [[cailiao-xuangou]]。

### 美缝材料
| 类型 | 更适合 | 注意 |
|---|---|---|
| 水泥基 | 干燥区、外墙 | 吸水易发霉发黑 |
| 真瓷胶 | 亮光砖、大理石 | 便宜亮，易黄变、收缩脱落，浅色客厅慎用 |
| 聚脲彩砂 | 阳台、厨卫、浅色砖 | 抗黄变耐磨，贵、施工难 |
| 环氧彩砂 | 卫生间湿区、室内全屋 | 防霉较稳，不适合阳台暴晒 |
| 氢化环氧彩砂 | 全屋 | 抗黄变更好，对施工要求高 |

## 种类避坑
- 釉面砖拒绝陶土坯，吸水高易裂。
- 通体砖铺前做防渗透，防酱油渗色。辨真假通体看截面纹理是否贯通；数码通体家装大多够用，重点看表面质感。
- 仿古砖深色建议面积 > 10㎡；厨卫选 R10–R11、微纹理釉面或柔光通体，不要荔枝面、沟槽过深。
- 微晶石娇贵，只适合背景墙。岩板算运输损耗和铺贴人工。
- 马赛克只点缀，人工大约 80–150 元/㎡ 且可翻倍。

## 铺完怎么验
国标 GB 50209-2010 与家装实操对照见 [[jiangong-yanshou]]。外观无崩瓷、裂纹，无明显色差、水波纹；美缝饱满不脱落。

## 日常维护
1. 中性清洁剂 + 软布 / 微湿拖把；禁止强酸强碱（氢氟酸、盐酸）和钢丝球。
2. 仿古 / 哑光砖：铺贴 15 天后可涂渗透型防污剂。
3. 美缝 / 环氧彩砂每年检查，局部开裂及时补，防污水渗基层。
4. 家具腿加软垫；地暖升降温速率 ≤ 2℃/h，减少热胀冷缩开裂。
