厨房是「一锤子」空间，水电和橱柜定了很难改。先定电器尺寸，再改水电。插座布局见 [[shui-dian]]。

## 开工前五件事
1. **洗碗机**：嵌入式要深度和隔壁柜里的水电，不要把水管电线燃气管挡在机位里。现场盯着交接。
2. **净水**：水槽下可能有末端净水、中央净水、软水、垃圾处理器，每个都要电和空间。
3. **开敞还是封闭**：先问当地燃气公司。很多地方必须封闭才能通气。预算够可用轨道玻璃 / 三联动做成半开半闭。开放式炒菜油烟会满屋。
4. **台面和板材**：普通家庭选硬度够的石英石（约 93% 石英）；岩板看准再买。板材 E1 以上、封边完整即可，不必只认不锈钢。高低台：炒菜区可比洗菜区低约 10cm。台下用塑钢垫条，水槽下贴铝箔。做真台下盆，提前开孔卡扣固定。
5. **冰箱单独回路** + 插座藏在柜内合适位置，避免包进柜子后插不上。

## 十装十不装
| 做 | 不做 |
|---|---|
| 极简地轨 | 普通地轨（磕绊积灰） |
| 侧吸油烟机 | 顶吸（跑烟撞头） |
| 吊柜通顶 | 不通顶落灰 |
| 弧形挡水 | 直角挡水发霉 |
| 切角橱柜 | 直角死角 |
| 抽屉收纳 | 拉篮易卡 |
| 大单槽 | 小单槽难洗锅 |
| 带开关的插座 | 普通五孔来回拔 |
| 高光面板 | 肤感不耐脏 |
| 台下盆 | 台上盆卫生死角 |

门套厨房推拉门侧更宜铝合金。吊顶选铝扣板便于检修，少选难拆的蜂窝大板。
吊柜做到顶、宽度不要超过地柜。台面不要装前挡水条，要有下挡水沿。先定油烟机再画柜。高低台可参考身高 ÷ 2 + 5 cm。安装用防霉玻璃胶。拉篮可自购（如悍高、酷太）。
相关预算见 [[yusuan-kanjia]]，半包谁买橱柜见 [[banbao]]。
