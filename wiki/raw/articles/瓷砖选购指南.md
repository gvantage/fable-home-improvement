## 一、先懂材料

瓷砖是常见建筑装饰材料，通常以黏土、石英砂等无机原料，经配料、压制、施釉、烧成等工序制成。特点是硬度高、耐磨、防水、易清洁，墙地均可使用。

选砖前先分清三类胚体：

| 类型 | 背面纹理 | 侧面胚体 | 要点 |
| --- | --- | --- | --- |
| 全瓷 | 弧形平行脊纹，呈分区排列 | 致密细腻，均匀中灰色 | 密度最高，适合地砖、厨卫 |
| 半瓷 | 细密菱形交叉网格 | 密度略低，浅灰色 | 介于全瓷与陶质之间 |
| 陶质 | 简单方格纹，有的印有 ISO | 更厚、更疏松，红褐色 | 吸水率高，多作室内墙砖 |

**原则：吸水率越低，瓷砖密度越高。**

## 二、按材质与吸水率分类（国标核心）

依据国家标准 GB/T 4100，按吸水率 E 划分：

| 类型 | 吸水率 E | 材质特点 | 性能表现 | 常见产品 |
| --- | --- | --- | --- | --- |
| 陶质砖 | E > 10% | 坯体疏松多孔、重量轻 | 强度低、怕冻、不防水 | 室内墙砖（瓷片） |
| 炻质砖 | 6% < E ≤ 10% | 坯体较密 | 耐磨一般，适合干燥地面 | 少量地砖、复古砖 |
| 细炻砖 | 3% < E ≤ 6% | 坯体密度中等 | 耐磨、防潮较好 | 仿古砖、外墙砖 |
| 炻瓷砖 | 0.5% < E ≤ 3% | 接近玻化、硬度高 | 耐磨抗冻，可户外 | 通体砖、仿古砖 |
| 瓷质砖 | E ≤ 0.5% | 高温烧结，玻化坯体 | 超耐磨、全防水、抗冻 | 抛光砖、抛釉砖、通体砖、岩板 |

### 选购关键

- **厨卫 / 阳台 / 外墙**：必须选瓷质砖（E ≤ 0.5%）
- **客厅 / 卧室**：可选瓷质或炻瓷砖（E ≤ 3%）
- **干燥墙面**：陶质瓷片（E > 10%）性价比高

## 三、常见瓷砖种类详解

### 1. 抛釉砖

表面施釉后高温烧制，分陶土（红坯）和瓷土（灰坯）两种基材。常见白底灰纹大理石效果。

| 项目 | 内容 |
| --- | --- |
| 优点 | 色彩丰富；防污性强；哑光款防滑性佳 |
| 缺点 | 耐磨性较弱（莫氏 5–6 度）；存在釉裂风险 |
| 适用 | 厨房墙面、卫浴空间、室内地面（选瓷质基材） |
| 场景备注 | 墙面、厨房、卫生间墙面；防污、易清洗 |

### 2. 通体砖

坯体到表面材质一致，未施釉的原生生态砖。颜色单一、内外同色。

| 项目 | 内容 |
| --- | --- |
| 优点 | 耐磨性强（莫氏 7 度）；防滑优异（摩擦系数 0.7+）；划痕不明显；可切割开槽且切口同色 |
| 缺点 | 花色少、设计感一般；易渗污，铺前需做防渗透处理（防酱油等渗色） |
| 适用 | 阳台地面、过道、玄关、商超等高频区域；有小孩爬地的家庭 |
| 风格 | 工业风（原始坯体质感） |

### 3. 抛光砖

通体砖表面抛光处理，亮度约 65–90 度，镜面感强，性价比高。

| 项目 | 内容 |
| --- | --- |
| 优点 | 性价比高；耐磨抗压（莫氏 6–7 度）；反光显亮、放大空间；脏了好擦 |
| 缺点 | 遇水易滑（摩擦系数可下降约 50%）；易显划痕；表面微孔易藏污；花色偏传统 |
| 适用 | 客厅、卧室、餐厅、办公室等干燥区域；采光一般的客厅 |
| 注意 | **不要铺卫生间**；避免卫浴等湿滑场所 |

### 4. 玻化砖

高温烧结、密度极高，接近玻璃化。

| 项目 | 内容 |
| --- | --- |
| 优点 | 吸水率极低、耐腐蚀、硬度高；耐磨等级最高（约 8 级）；水擦即干、不留痕 |
| 缺点 | 遇水偏滑，需搭配防滑设计；花色有限；需定期打蜡；铺贴必须用瓷砖胶（防空鼓） |
| 适用 | 客厅、酒店大堂等高档场所；也可用于厨卫地面（看具体防滑工艺） |
| 风格 | 现代极简（镜面效果） |

### 5. 马赛克砖

20×20 mm 至 50×50 mm 小型装饰砖，材质含陶瓷、玻璃、石材。

| 项目 | 内容 |
| --- | --- |
| 优点 | 艺术性强、拼图灵活；防滑好；防水、耐酸碱；适合曲面、腰线、水池 |
| 缺点 | 铺贴成本高（人工费约 80–150 元/㎡，人工可翻倍）；缝隙多、易积垢、难清洁 |
| 适用 | 泳池饰面、卫浴背景墙、局部艺术装饰 |
| 注意 | 不适合大面积铺地，宜作点缀 |

### 6. 仿古砖

哑光做旧、砂面肌理，色调偏复古。

| 项目 | 内容 |
| --- | --- |
| 优点 | 防滑耐磨、氛围感强；哑光不刺眼；轻微划痕不明显；适配美式、侘寂、田园 |
| 缺点 | 凹凸面易积灰、清洁略难；色调偏深，小户型通铺易显压抑 |
| 适用 | 地面、厨房、阳台、美式/田园客厅、背景墙、外墙 |
| 注意 | 避免深色用在小空间，建议面积 > 10㎡ 再上深色；通常需要美缝 |
| 风格 | 复古文艺（做旧质感，可搭配马赛克拼花） |

### 7. 釉面砖

坯体上施釉烧成，分亮面、柔光、哑光，花色最多，家装最常用。

| 项目 | 内容 |
| --- | --- |
| 优点 | 款式丰富、装饰性强；釉层致密、抗污好擦；价格亲民、选择多 |
| 缺点 | 釉层薄，硬物易刮花崩瓷；低端款吸水率高，不适合积水区；亮面遇水滑 |
| 适用 | 厨房、卫生间、背景墙；室内地面需选瓷质基材 |
| 注意 | 拒绝陶土坯（吸水率高、易开裂） |

### 8. 木纹砖

仿实木地板纹理与规格，兼具瓷砖性能与木质观感。

| 项目 | 内容 |
| --- | --- |
| 优点 | 观感接近实木、温润自然；防水防潮、防虫防霉、不变形；比木地板更好打理，回南天不发霉 |
| 缺点 | 铺贴精度要求高，缝不齐会显乱；低端款纹理僵硬、缺木感 |
| 适用 | 喜欢木色但不想养木头的人；卧室、阳台；一楼潮房地面尤其合适 |

### 9. 哑光砖

表面漫反射，略有颗粒感，不反光。

| 项目 | 内容 |
| --- | --- |
| 优点 | 防滑耐磨；质感低调；强光下不刺眼；湿水仍相对防滑 |
| 缺点 | 时间久了更容易藏灰，需勤清理 |
| 适用 | 阳台、需防滑区域、采光好的客厅；有老人小孩、防滑优先的厨卫；喜欢低调度质感的客厅 |

### 10. 柔光砖

半反射、触感细腻，介于亮面与哑光之间。

| 项目 | 内容 |
| --- | --- |
| 优点 | 温和高级、不刺眼；拖地不显水印 |
| 注意 | 防滑和抗污要看具体工艺 |
| 适用 | 无主灯设计、奶油风、现代简约客厅 |

常见柔光工艺分类：天鹅绒、干粒模具刷抛、纳米精雕原石釉、肌肤釉、莫奈干粒、原珠莫奈干粒微抛、干粒精雕柔抛、莫奈干粒数码釉、超细干粒刷抛、加厚真石釉面、数码釉柔光精雕、干粒半抛。

### 11. 微晶石砖

表面复合微晶玻璃层，玉质通透、光泽豪华，属高端装饰砖。

| 项目 | 内容 |
| --- | --- |
| 优点 | 晶莹豪华、美观度高；抗污易打理；吸水率极低 |
| 缺点 | 表层脆、硬物易崩；耐磨较差，不适合高频地面；价格贵，普通家装性价比一般 |
| 适用 | 高端宅邸、大堂、背景墙（墙面为主） |

### 12. 岩板砖

大规格烧结板，纹理大气，可墙、地、台面、背景墙通用。

| 项目 | 内容 |
| --- | --- |
| 优点 | 平整度极高、整体感强；耐热、近零吸水、抗污抗刮抗压；缝少，极简首选 |
| 缺点 | 价格偏高；重量大、运输易损；铺贴精度要求高，人工贵 |
| 适用 | 墙地一体、台面、极简大平层 |

### 13. 大理石瓷砖 / 仿大理石瓷砖

复刻天然石材纹理与通透感，避开天然石辐射与娇贵问题，轻奢首选替代。

| 项目 | 内容 |
| --- | --- |
| 优点 | 纹理高级、无辐射；比天然大理石更硬、不渗污不变形；好打理、防水，可通铺 |
| 缺点 | 低端款纹理重复、僵硬；高端通体版不便宜；亮面款防滑一般；买时要盯釉面质量 |
| 适用 | 客厅、餐厅、全屋地面 |

### 14. 防滑砖

表面做凹凸或颗粒处理。

| 项目 | 内容 |
| --- | --- |
| 优点 | 抓地力强、防潮、安全性高 |
| 缺点 | 更容易藏污 |
| 适用 | 卫生间、厨房、阳台 |

## 四、表面质感怎么选

先看采光，再看日常打理。

| 质感 | 特点 | 优点 | 注意 | 适合谁 |
| --- | --- | --- | --- | --- |
| 亮面砖 | 镜面、反光明显 | 显亮、显通透、耐污好清洁 | 强光下刺眼；水渍更明显；遇水滑 | 想空间更明亮通透；采光一般的客餐厅；想放大空间感 |
| 柔光砖 | 半反射、触感细腻 | 温和高级、不刺眼、不显水印 | 防滑抗污看具体工艺 | 想整体更柔和舒适；无主灯、奶油风、现代简约 |
| 哑光砖 | 几乎不反光、略有颗粒 | 低调耐看、防滑更安心 | 更易藏灰，需勤清理 | 想低调又要防滑；阳台、采光好的客厅、老人小孩家庭 |

## 五、按功能与风格分类

### 按功能场景

| 类型 | 核心功能 | 代表产品 |
| --- | --- | --- |
| 防滑 | 糙面或防滑剂，约 R9–R11 | 通体砖、仿古砖、防滑釉面砖 |
| 耐磨 | 莫氏硬度 ≥ 6，耐刮 | 抛光砖、通体砖 |
| 抗菌 | 釉面含银离子 / 光触媒 | 高端抛釉砖 |
| 户外 | 抗冻抗污，E ≤ 0.5% | 通体砖、炻质仿古砖 |
| 背景墙 | 大规格（900×1800 mm+）、高颜值 | 大板釉面砖、微晶石 |

### 按外观风格

| 风格 | 特点 | 适用瓷砖 |
| --- | --- | --- |
| 大理石纹 | 仿天然石材纹理 | 抛釉砖 |
| 木纹 | 仿真木肌理 | 木纹砖（釉面瓷质） |
| 水泥 / 工业 | 灰黑色调、哑光质感 | 水泥砖、微水泥砖 |
| 复古 | 做旧色 + 不平整表面 | 仿古砖 |
| 极简纯色 | 纯色无花 | 通体砖、哑光砖 |
| 彩色拼花 | 小颗粒拼图 | 马赛克 |

### 按表面工艺

| 工艺 | 特点 | 代表产品 | 适用场景 | 注意事项 |
| --- | --- | --- | --- | --- |
| 抛光 | 镜面高亮 | 抛光砖 | 客厅、商场 | 防滑差，遇水滑 |
| 施釉 | 坯体 + 色釉，花色丰富 | 抛釉砖、仿古砖 | 全屋墙地 | 选耐磨釉（PEI ≥ 3 级） |
| 微晶复合 | 表面覆玻璃层 | 微晶石 | 背景墙（仅墙面） | 娇贵易刮，不铺地 |
| 通体无釉 | 坯体本身有质感 | 通体砖、玻化砖 | 户外、厨卫地面 | 防滑耐用，花色有限 |
| 柔光 / 哑光 | 低反光、质感温和 | 柔光砖、哑光仿古砖 | 卧室、高端商业 | 防滑较好、抗污较好 |
| 浮雕模具 | 凹凸或 3D 肌理 | 仿古砖、防滑砖 | 阳台、卫生间、庭院 | 纹理藏灰，需定期清洁 |

## 六、门店选购实操

店里就能做的基础判断：

### 看三样：表面、声音、平整度

1. **看釉面**：观察是否平整细腻，有无针孔、杂点、色差、崩边。
2. **听声音**：轻敲砖面，声音越清脆，通常砖体越致密。
3. **看平整度**：几块砖拼在一起看缝隙和高低差，越平整，后期铺贴效果越好。

### 再看三点：吸水率、重量、耐刮性

4. **看吸水率**：往砖背面滴水，扩散越慢，吸水率越低（越好）。
5. **掂重量**：同尺寸下，更沉、更扎实的通常密度更高。
6. **测耐刮**：用钥匙等硬物轻划表面，不留痕的更耐用。

## 七、空间适配与决策口诀

### 空间适配法则

| 空间 | 首选 | 说明 |
| --- | --- | --- |
| 厨卫 | 防污釉面砖 / 防滑通体砖 | 干湿分区、防滑防污优先 |
| 客厅 / 卧室 | 抛光砖 / 玻化砖 | 耐磨优先；采光差可选亮面 |
| 商业空间 | 玻化砖 / 通体砖 | 高强度、高人流 |
| 艺术装饰 | 马赛克 / 仿古砖 | 风格化点缀 |
| 阳台 / 过道 / 玄关 | 通体砖、木纹砖、防滑砖 | 高频踩踏、防滑防潮 |

### 决策口诀

> **耐磨看玻化，防滑选通体，艺术马赛克，省钱抛光砖，风格仿古砖，省心釉面砖。**

建议结合三个维度综合选：

1. **空间功能**：干湿、人流量
2. **预算区间**：材料 + 施工
3. **设计风格**

## 八、耐磨、防滑、维护与成本对比

### 耐磨性能天梯

玻化砖（8 级）> 通体砖（7 级）> 抛光砖（6–7 级）> 仿古砖（5–6 级）> 釉面砖（5 级）

走廊、商场等高频区，优先选前三位。

### 防滑安全等级（由高到低）

1. 通体砖（糙面）
2. 马赛克砖（凹凸缝）
3. 仿古砖（哑光釉）
4. 抛光砖慎用（遇水摩擦系数可下降约 50%）

### 清洁维护

| 维护难度 | 类型 | 原因 |
| --- | --- | --- |
| 高维护 | 马赛克、玻化砖 | 缝多易积垢；玻化砖需定期打蜡 |
| 低维护 | 釉面砖、通体砖 | 抗污釉层；通体砖需做好渗透防护 |

### 成本控制

- **材料成本大致**：玻化砖 > 仿古砖 > 马赛克 > 釉面砖 > 通体砖 > 抛光砖
- **施工成本大致**：马赛克（人工翻倍）> 仿古砖（需美缝）> 通体砖（需防护处理）

### 避坑要点

- **釉面砖**：拒绝陶土坯，吸水率高易开裂
- **玻化砖**：铺贴必须用瓷砖胶，防空鼓
- **仿古砖**：避免深色小空间，建议 > 10㎡ 再上深色
- **通体砖**：铺前做防渗透处理，防酱油渗色
- **抛光砖**：不要铺卫生间
- **微晶石**：不要当高频地砖用
- **岩板**：算清运输损耗和铺贴人工

## 九、包装附录速查（必看）

选砖必须认准包装上的「附录」。吸水率越低，密度越高。

| 附录 | 生产工艺 | 吸水率 E | 分级 |
| --- | --- | --- | --- |
| 附录 A | 挤压陶瓷砖 | E ≤ 0.5% | AIa |
