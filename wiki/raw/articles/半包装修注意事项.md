

半包装修注意事项与执行手册

# 一、总览与责任分工（谁做什么）
- 装修公司负责：设计 + 施工（墙体拆改、水电、瓦工、木工、油漆等）+ 辅材（合同须列明辅材品牌与规格）。
- 业主负责：主材、家具、家电、软装的采购与验收（提前列清单并与施工节点对齐）。
- 合同应明确：工程范围、材料清单（主材/辅材及品牌型号）、施工工艺与标准、付款节点、工期与违约责任、增项审批与收费规则、保修与售后条款。

# 二、半包材料采购（按工序与时间节点）
1. 设计方案确定后
   - 可预定：地暖、新风系统、中央空调、电线与网线等大件/隐蔽工程。

2. 水电进场前
   - 确定并一次性购买瓷砖（墙砖、地砖）。注意：同款不同批次可能有色差，尽量一次买齐并留备品。

3. 瓦工结束前
   - 确定并订购：橱柜、燃气灶、油烟机、窗户等。
   - 瓦工结束后可订：卫浴洁具、地漏、开关插座、五金。建议早点订套门，否则可能会等货。

4. 木工阶段
   - 吊顶结束后订制衣柜、定制家具等。

5. 油漆工到刮腻子后
   - 订吊顶、浴霸、排气扇、厨房电器等。

6. 刷乳胶漆期间
   - 可订：地板、灯具、窗帘等软硬结合件。

7. 油漆工完工后
   - 订淋浴房、辅料地板、放置家具、安装窗帘与软装。

# 三、半包报价对比（如何判断报价与施工质量）
- 查看报价单是否完整：材料（主辅材）、数量、品牌、型号、单价、施工项目应写明。
- 不要只看总价：低价可能隐藏减项或偷工减料，必须看明细与施工标准。
- 比较施工工艺与标准：施工流程、隐蔽工程验收标准（强电弱电、水路走向、防水处理）要明确。
- 注意是否包含隐含费用：材料搬运费、管理费、垃圾清运、临时水电等。
- 施工工艺书写越清楚越好：便于验收与事后维权。
- 明确哪些材料业主可指定品牌并写入合同。

# 四、半包增项与漏项（合同要点）
- 在合同中约定增项审批与费用上限（建议增项总额不得超过预算金的 5%，或明确增项审批流程）。
- 防水高度：合同里写明防水高度（建议 1.8m，若依据不同部位可注明例外）。
- 防止故意分项报价：要求整体报价与单价清单，避免把本应整体报价的项目拆分成若干项收取额外费用。
- 常见漏项需列清单并写进合同：
  - 开关插座、踢脚线、地漏、五金、包立管、保温防潮工艺、材料建渣搬运费、门槛石、铝扣板、打拆/新建墙体、封门洞等。

# 五、水电改造与全景留底（拍照与记录规范）
目的：水电完工后拍全景留底，便于日后定位问题、维修和维权。

拍摄与记录要点：
- 全景 + 局部结合：先拍整个房间走线，再拍分线盒、电箱、强弱电交汇处、每个插座背后位置等特写。
- 分类拍照：强电、弱电、给水、排水、燃气等分别拍摄并标注。
- 标注尺寸与高度：如离地高度（示例：80cm）、距窗/门的具体位置。
- 编号与文字记录：对每条主要管线编号（A1/A2……），在记录表中写明编号对应回路/用途。
- 命名与备份：建议文件名格式 YYYYMMDD_房间_部位_编号.jpg；云端+本地双备份。
- 存档用途：维修快速定位、隐蔽工程验收痕迹、与施工方对账与维权证据。

示例记录项（表格字段样式）：
- 房间 | 日期 | 照片文件名 | 编号 | 描述（走向、材质、离地高度） | 材料品牌 | 施工单位/师傅 | 备注

# 六、半包容易出现的坑与防范（实务建议）
1. 中途加价
   - 防范：签合同前做详尽报价与物料清单，约定增项审批流程与上限。

2. 后续款项被提前催交
   - 防范：合同写清阶段性验收标准与对应付款比例，付款与验收挂钩，保留尾款以保障保修期。

3. 面积计算不实
   - 防范：现场共同量房并复核关键尺寸，把面积与计费规则写入合同。

4. 拖延工期
   - 防范：合同写明总工期与关键节点、延期赔付或违约金机制。

5. 偷换材料
   - 防范：合同列明辅材品牌/型号或替代标准，材料进场逐一查验并拍照留证。

6. 合同责任含糊
   - 防范：签正规书面合同，明确工程范围、验收标准、保修与工伤责任、争议处理方式。

# 七、装修公司工作与业主本人工作清单（逐项对照）
装修公司（通常负责）
- 设计输出：平面图、效果图、透视图。
- 施工：墙体拆改、水电改造、瓦工、木工、油漆、安装辅材等。
- 提供辅材：水泥、黄沙、防水涂料、腻子、乳胶漆、电线、线管、石膏板等（合同详列品牌/规格）。

业主（通常负责）
- 购买主材：墙纸/墙布、瓷砖（墙/地）、门槛石、踢脚线、地板、门窗、卫浴洁具、五金、开关面板等。
- 家具（按功能分区列清单并确认尺寸与交货期）。
- 家电：中央空调、热水器、灶具、油烟机、冰箱、洗衣机、烘干机、电视等（大件提前预定并告知设计与施工方尺寸）。
- 软装：窗帘、床上用品、抱枕、装饰品、地毯等（通常在主工程完成后定制/购买）。

# 八、合同与验收要点（建议条款清单）
- 报价与明细：列明材料、数量、品牌、型号、单价。
- 阶段验收与付款：阶段名称、验收内容、付款比例（例如：签约 10%、开工 20%、水电验收后 20%……尾款 5%-10%保留至保修期）。
- 增项审批：增项必须书面审批并列明单价与计费规则，上限规定。
- 工期与赔偿：写明开工/竣工日期、关键节点、逾期赔偿标准。
- 材料入场验收：材料到场逐项验收并拍照留证，注明私自调换处罚。
- 隐蔽工程验收：水电、防水、预埋件等隐蔽工程必须拍照并签字确认后方可覆盖。
- 保修条款：保修范围、保修期、响应时间、维修费用分担。
- 争议解决：明确仲裁/诉讼地、适用法律或仲裁机构。

# 九、拍照与记录文件命名与存储规范（便于检索与维权）
- 文件名建议：YYYYMMDD_房间_部位_编号.jpg（例如：20251120_客厅_强电入线_01.jpg）
- 文件夹结构建议：/装修项目/房间名/隐蔽工程/日期/
- 备份：云端（百度网盘/Google Drive）+ 本地硬盘，合同、报价、付款凭证亦统一归档。

# 十一、遇到问题或纠纷的处理流程
1. 先留证据：合同、报价单、付款凭证、材料到场单、验收单、现场照片（尤其隐蔽工程）。
2. 与施工方书面沟通并留存沟通记录（短信/微信/电子邮件/签收单）。
3. 若协商不成：依据合同启动仲裁或诉讼；可先咨询当地消费者协会或住建委。
4. 必要时：聘请第三方监理或鉴定机构作质量评估、出具报告作为证据。

什么是半包？
半包装修是什么呢？
半包是指施工方负责施工和辅材的采购，主材需要业主自行购买。
1.辅材包括什么呢？
- 水电：电线、线管、网线、线盒、保温棉
- 木工：龙骨、石膏板、各种板材
- 泥工：水泥、沙子、防水、红砖、陶粒砖
- 油工：墙固、腻子、石膏、乳胶漆、防裂网
2.主材包括什么呢？
- 主材：木地板、地面的瓷砖、踢脚线
- 门：防盗门、卧室门、拖拉门、厨卫门
- 灯具：吸顶灯、筒灯、射灯、吊灯
- 五金：门把手、门锁、门吸、开关插座、水槽、龙头、地漏
- 定制柜：橱柜、衣柜、鞋柜、电视柜
- 吊顶：铝扣板
- 石材：窗台石、过门石、台面
- 卫生间：浴室柜、坐便器、浴缸
