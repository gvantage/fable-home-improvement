## A. 开工前：物业、预算、垃圾、钥匙

图片：`0 (10).jpeg`

1. **物业办理装修手续**  
   预备购房合同、身份证、装修图纸。确认施工时段；知道承重墙、外墙改动禁令；交装修押金和垃圾清运费。红线强调：索要物业盖章的施工许可。
2. **制作装修预算表，控制预算**  
   预算拆五类：主材、辅材、人工、家电、软装。总预算预留 10%–15% 应急。红线强调：标注每类主材预算上限，避免超支。
3. **问清垃圾清运流程**  
   分两段：下楼到物业指定点、指定点到场外。分清物业场内清运费和场外建废清运费。红线强调：确认是否有超时堆放罚金，书面敲定报价。
4. **购买装修密码盒**  
   放在入户门旁；登记开锁密码；定期更换；完工立即改密。

## B. 开工保护与必须提前定的系统

图片：`0 (11).jpeg`（末段被裁，续到 `0 (12)`）

1. **地面保护膜**：优先加厚+防滑底；入户门槛和电梯轿厢加厚铺，防材料搬运划伤。
2. **临时马桶**：选可冲水款，配除味耗材，减少工地异味和污水堵塞。
3. **下水道保护盖**：厨卫下水口全部盖严，防水泥、碎渣落入。
4. **玻璃胶**：厨卫潮湿区用防霉中性胶；提前备透明和瓷白。
5. **封窗、防盗门**：确认型材壁厚；玻璃钢化且有 3C；核对五金品牌；锁芯优先 C 级；约定生产周期和进场安装节点。
6. **新风/中央空调、地暖、净水器、管线机**：商家现场勘察点位和管路走向。红线：柜内预留净水器进水和插座。核对质保期。
7. **全屋定制**：板材环保等级优先 ENF；看五金品牌和计价规则（原文在「谨防增项套路」处被裁切）。

## C. 合同、验房、插座初稿；拆改期锁电器尺寸

图片：`0 (12).jpeg`  
拆改期标注约 **7–10 天**。

1. **提前选好全屋定制商家**：对比板材环保（优先 ENF）、五金品牌、计价规则；谨防增项套路；敲定基础方案。
2. **核验房屋**：空鼓、渗水试验、门窗密封；记录原房屋问题，该找开发商修的先修。
3. **敲定半包合同**：逐条核对辅材品牌、施工范围、延误赔偿。口头承诺写入合同附件。
4. **规划全屋插座初稿**：按家具尺寸和电器落位预判，避免后期插座不够。
5. **拆改期间提前选厨房电器及扫地机器人等**：不必立刻下单，但必须锁定型号。嵌入式冰箱、蒸烤箱、洗碗机要把进深和宽度交给橱柜厂开孔。扫地机基站预留上下水。
6. **智能家居、电动晾衣架**：需要的先选型；晾衣架要买好（与预埋衔接，见下节）。

## D. 预埋件、止逆阀、隔音、交底会

图片：`0 (13).jpeg`

1. **洁具预埋**（马桶、龙头、花洒等）  
   智能马桶预留电源；电动晾衣架确认吊顶预留长宽和承重；恒温花洒提前核对预埋内丝间距。
2. **烟道止逆阀**：优先不锈钢密封款；口径匹配自家烟道，防邻居油烟倒灌。
3. **隔音棉**：包裹排水管，降低流水声。
4. **插座布局**：床头、餐边、书桌、大电器、扫地机、智能家居分区规划；红线：多留备用插座。
5. **封窗商家初次测量**：拆墙后标记洞口净尺寸；确认外墙交接防水和打胶方案。
6. **水电交底**：设计师、工长、水电工、全屋定制、封窗、空调/管线机商家到场。红线：现场复核每一个点位；拍照并保留签字纸质记录。

## E. 水电期采购与记录（工期约 10–15 天）

图片：`0 (14).jpeg`

1. **地漏**：淋浴深水封防臭；洗衣机专用接口款；干区普通防臭。先问清需求再买。
2. **强弱电箱**：弱电箱给光猫、路由留散热空间。墙砖、地砖、踢脚线提前选定；核对色号，需要则泡水预处理。木门提前定制，核对门洞净高净宽。
3. **窗台石等石材**：飘窗/窗台优先石英石。红线：圆弧倒角，降低磕碰。
4. **全屋定制、橱柜初次测量、出方案**：按实际水电点位调整柜体。红线：确认嵌入式家电预留空间。
5. **水电点位拍照记录、粉笔标记**：强电/弱电、给水/排水分类拍全景。红线：归档，避免后期打孔打到管线。

## F. 半包定义、优点、缺点

图片：`0 (15).jpeg` 标题「二、半包」

**定义**：业主买主材（地砖、洁具、橱柜等）；装修公司提供辅材（水泥、砂、电线、水管等）和人工。

**优点**

- 主材选择自主：品牌、风格、价位自己定（例：冲环保选高等级地板涂料；冲品质选名牌洁具厨电）。
- 相对省钱：业主直对材料商可议价；公司只包人工+辅材，总价通常低于全包、更好控。辅材用量相对透明。
- 公司给专业支持：施工管理、工人排班、进度；水电按规范；墙面按基材选工艺。

**缺点**

- 业主要花时间和精力：调研比价；还要在公司和材料商之间协调到货与施工窗口。

## G. 半包流程表：开工前期 + 拆改

图片：`0 (16).jpeg`

### 一、开工前期（约 30 天）

| 角色 | 事项 |
|------|------|
| 装修公司 | 量房；出图（约 20 天）；含毛坯勘察 |
| 业主 | 办开工手续（物业施工许可、工人出入证）；交装修押金；遵守物业规范 |
| 准备购买 | 中央空调、地暖、新风、净水器（开工前交定、约安装窗口）；防盗门窗；全屋定制橱柜衣柜 |
| 注意 | 生活习惯跟设计师谈透再开工；预算越准后期越不容易超；主材按阶段提前买。雨天看外墙渗水后再确认施工预算 |

### 二、拆改阶段（约 10 天）

| 角色 | 事项 |
|------|------|
| 装修公司 | 铲墙皮、拆除、砌墙、封阳台、清运垃圾、橱柜初测 |
| 业主 | 确认地暖铺法；确认厨电型号尺寸（嵌入式先定尺寸不必先买）；联系建废清运车辆 |
| 准备购买 | 临时马桶、下水保护盖；烟管和止逆阀（水电期预埋）；需预埋的洁具（壁挂马桶、入墙龙头、暗装花洒）；强弱电箱 |
| 注意 | 地漏保护防堵塞；净水、管线机、垃圾处理器要一起协调（原文底部被裁） |
